# Чек-лист безопасности для курса Moodle

## 1. Учётная запись администратора
- Установлен сложный пароль (длина 12 символов, буквы в разных регистрах, цифры, специальные символы).

## 2. Права роли «Студент»
- Проверена роль «Студент»: убраны все права, дающие доступ к настройкам сайта, управлению пользователями и резервному копированию.
- Студенты могут только просматривать материалы, проходить тесты и участвовать в интерактивах.

## 3. Ограничения на загрузку файлов
- В разделе «Политики сайта» установлен максимальный размер загружаемого файла: **40 МБ**.
