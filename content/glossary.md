1. Переменная – именованная область памяти для хранения данных.
2. Тип данных – классификация значений (числа, строки, списки и т.д.).
3. Список (list) – изменяемая упорядоченная коллекция элементов.
4. Кортеж (tuple) – неизменяемая упорядоченная коллекция.
5. Словарь (dict) – неупорядоченная коллекция пар «ключ-значение».
6. Множество (set) – неупорядоченная коллекция уникальных элементов.
7. Условный оператор (if, elif, else) – конструкция для ветвления кода.
8. Цикл for – итерация по последовательности.
9. Цикл while – повторение кода пока условие истинно.
10. Функция (def) – блок кода, выполняющий определённую задачу.
11. Параметр – переменная, указанная в определении функции.
12. Аргумент – значение, передаваемое функции при вызове.
13. Возвращаемое значение (return) – результат работы функции.
14. Модуль – файл с кодом Python, который можно импортировать.
15. Пакет – каталог с модулями и файлом __init__.py.
16. Исключение (exception) – ошибка, возникающая во время выполнения.
17. Обработка исключений (try, except) – механизм перехвата ошибок.
18. Класс (class) – шаблон для создания объектов.
19. Объект – экземпляр класса.
20. Метод – функция, принадлежащая объекту.
21. Атрибут – переменная, принадлежащая объекту.
22. Наследование – создание нового класса на основе существующего.
23. Декоратор – функция, изменяющая поведение другой функции.
24. Генератор – функция, возвращающая итератор с помощью yield.
25. Менеджер контекста (with) – конструкция для управления ресурсами.
