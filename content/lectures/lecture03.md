# Lecture 3 — Циклы for и while
**Тема:** Повторение действий с помощью циклов, операторы break и continue.
**Цель урока:** Научиться использовать циклы для многократного выполнения кода и управления повторениями.
**Время:** ~20 мин.
**Ключевые понятия:** цикл for, цикл while, range(), break, continue, итерация

## 1) Введение
Циклы позволяют выполнять один и тот же блок кода многократно. Это необходимо при обработке последовательностей данных, при вычислениях с накоплением и во многих других ситуациях. В Python есть два основных вида циклов: `for` и `while`.

## 2) Основная часть
**Цикл for** используется для перебора элементов последовательности (списка, строки, диапазона чисел). Часто применяется с функцией `range()`.

```python
# Вывести числа от 0 до 4
for i in range(5):
    print(i)
    range(5) генерирует числа 0,1,2,3,4. Можно указать начало и конец: range(2, 6) → 2,3,4,5. Третий параметр — шаг: range(1, 10, 2) → 1,3,5,7,9.


for char in "Python":
    print(char)


Цикл while выполняется до тех пор, пока условие истинно. Условие проверяется перед каждой итерацией.


count = 0
while count < 5:
    print("Счётчик:", count)
    count += 1   # увеличиваем, чтобы цикл когда-нибудь завершился


Операторы управления циклом:

· break — немедленно прерывает выполнение цикла.
· continue — пропускает оставшуюся часть текущей итерации и переходит к следующей.

Пример с break (поиск первого чётного числа):


numbers = [1, 3, 5, 6, 7, 9]
for num in numbers:
    if num % 2 == 0:
        print("Найдено чётное:", num)
        break


Пример с continue (вывод только нечётных):


for num in range(10):
    if num % 2 == 0:
        continue
    print(num)


3) Пример/практика

Напишем программу, которая суммирует все числа от 1 до введённого пользователем N.


N = int(input("Введите число N: "))
sum = 0
for i in range(1, N+1):
    sum += i
print("Сумма от 1 до", N, "равна", sum)
