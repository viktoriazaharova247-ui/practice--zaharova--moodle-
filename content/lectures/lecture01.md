## 1) Введение
Python — высокоуровневый язык программирования, который широко используется для веб-разработки, анализа данных, автоматизации и многого другого. ## 2) Основная часть
Python является интерпретируемым языком: код выполняется построчно специальной программой — интерпретатором.

**Первая программа:** выведем на экран фразу "Привет, мир!".
```python
print("Привет, мир!")

Переменные — это именованные ячейки памяти для хранения данных. В Python переменная создаётся в момент первого присваивания. Тип переменной определяется автоматически (динамическая типизация).

name = "Анна"      # строка (str)
age = 25           # целое число (int)
height = 1.68      # число с плавающей точкой (float)
is_student = True  # булево значение (bool)

Чтобы вывести значение переменной, используйте print:

print("Имя:", name)
print("Возраст:", age)

Ввод данных: функция input() позволяет получить данные от пользователя.

user_name = input("Как вас зовут? ")
print("Приятно познакомиться,", user_name)

Обратите внимание: input() всегда возвращает строку. Если нужно число, выполните преобразование:

age = int(input("Сколько вам лет? "))
3) Пример/практика

Напишем программу, которая запрашивает имя и возраст пользователя, а затем выводит приветствие и сообщение о том, сколько лет ему будет через год.

name = input("Введите ваше имя: ")
age = int(input("Сколько вам лет? "))
next_year_age = age + 1
print("Привет,", name)
print("Через год вам будет", next_year_age, "лет.")
