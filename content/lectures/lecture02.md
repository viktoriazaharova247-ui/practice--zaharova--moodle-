### Лекция 2: Условные операторы

```markdown
# Lecture 2 — Условные операторы
**Тема:** if, elif, else, логические выражения, сравнения.
**Цель урока:** Научиться использовать ветвления в программах для принятия решений.
**Время:** ~20 мин.
**Ключевые понятия:** условный оператор, if, elif, else, логические операторы (and, or, not), сравнения

## 1) Введение
Часто в программе необходимо выполнять разные действия в зависимости от условий. Например, проверить возраст пользователя и дать доступ только совершеннолетним. Для этого в Python используются условные операторы.

## 2) Основная часть
**Конструкция if** имеет следующий синтаксис:
```python
if условие:
    # блок кода, который выполняется, если условие истинно
    Условие — это выражение, которое может быть истинным (True) или ложным (False). Для сравнения используются операторы: == (равно), != (не равно), <, >, <=, >=.

age = 18
if age >= 18:
    print("Вы совершеннолетний")

if-else позволяет задать альтернативный блок:

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")

if-elif-else для нескольких условий:

if age < 7:
    print("Вы дошкольник")
elif age < 18:
    print("Вы школьник")
else:
    print("Вы взрослый")

if age < 7:
    print("Вы дошкольник")
elif age < 18:
    print("Вы школьник")
else:
    print("Вы взрослый")

Логические операторы позволяют комбинировать условия:

· and — истинно, когда оба условия истинны.
· or — истинно, когда хотя бы одно истинно.
· not — инвертирует значение.

x = 10
if x > 5 and x < 15:
    print("x находится в диапазоне от 5 до 15")

3) Пример/практика

Напишем программу, которая определяет, является ли год високосным. Год високосный, если он кратен 4, но не кратен 100, кроме случаев, когда он кратен 400.

year = int(input("Введите год: "))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(year, "год - високосный")
else:
    print(year, "год - не високосный")
